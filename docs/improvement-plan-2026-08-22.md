## 5. المرحلة 3 - الأداء وتجربة الاستخدام (أسبوع إلى أسبوعين)

### باكند
1. **Streaming للودجت**: حاليا انتظار كامل (~2s+) قبل أول حرف. فعّل SSE/streaming من DeepSeek للودجت (واتساب لا يدعمه بنفس الطريقة).
2. **RAG تدريجي**: المعرفة كاملة تُحقن بكل طلب (سقف 60k حرف). ابدأ بتقسيم chunks + بحث دلالي (embeddings) عندما يتجاوز أي عميل ~15k حرف. هذا أيضا يحل مشكلة رفض sanityCheck للمعرفة الكبيرة.
3. **عدّ العدادات بعد الكاش**: عداد rate limit يزيد قبل فحص كاش الردود - رسائل الكاش الرخيصة تلتهم سقف الفاتورة.
4. **تحليلات بدون مسح كامل**: `/admin/api/analytics` والـdashboard يعيدان قراءة كل ملفات الزبائن عند كل طلب. عداد تراكمي يُحدَّث عند كل رسالة بدل إعادة الحساب.

### فرونت
1. **استبدال Tailwind CDN** (نسخة التطوير!) ببناء محلي عبر CLI مع purge. النسخة الحالية غير آمنة للإنتاج وتسبب FOUC.
2. **إصلاح قائمة الموبايل في dashboard.html:47-50**: القائمة الجانبية تختفي تحت 900px بدون بديل، وزر الخروج داخلها = المستخدم على الهاتف لا يستطيع تسجيل الخروج.
3. **إصلاح innerHTML**: `onboard.html:283` يحقن اسم الملف بدون تهريب (XSS محلي). نفس النمط في admin-dashboard.html:427 وchat-widget.js:59-65.
4. **توحيد الهوية البصرية**: صفحات عامة Material-3 أزرق مقابل أدمن/بورتال ثيم teal يدوي.
5. **Accessibility أساسية**: focus trap للمودالات، Esc للإغلاق، aria-live لرسائل الشات، دعم LTR اختياري للودجت.
6. **حسم الروابط الميتة**: dashboard "البوتات" تشير خطأ إلى /public/signup، و"المحادثات/التقارير" placeholders، وlanding footer يربط /docs (المطلوب غلقه).

## 9. قائمة النشر على VPS

```bash
# 1) على جهازك المحلي - فحوص أخيرة
npm test && npm run build:css

# 2) ارفع الكود (tar فوق ssh زي عادتك)
#    استثنِ node_modules وdata و.env عن الرفع

# 3) على السيرفر
npm install --omit=dev
# تأكد من .env: META_APP_SECRET موجود (إجباري لويبهوك واتساب هلق)
# اختياري: WIDGET_STREAMING=true (افتراضي مفعّل)

# 4) ابنِ CSS إذا ما رفعت tailwind.css جاهز
npx tailwindcss -c tailwind.config.js -i src/public/tailwind.input.css -o src/public/tailwind.css --minify

# 5) إعادة تشغيل pm2 ومتابعة اللوج
pm2 restart ai-chat-bot && pm2 logs --lines 50

# 6) تحقق حي
curl -s https://YOUR_DOMAIN/health
# ويبهوك: ابعت رسالة واتساب حقيقية وراقب اللوج (403 توقيع = مشكلة META_APP_SECRET)

# 7) بعد أول تشغيل ناجح: دوّر مفاتيح Virtualizor/Google المسربة (بند 0.5)
```

ملاحظة nginx: البث (SSE) شغال بدون تعديل config - الهيدر X-Accel-Buffering:no مبعوت من التطبيق.
